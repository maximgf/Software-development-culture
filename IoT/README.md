# **Инструкция по запуску приложения**

Это руководство поможет вам развернуть FastAPI-сервер с Telegram-ботом для уведомлений о регистрации устройств.  

---


### **Установка зависимостей**

- Python 3.8+
- Установленные зависимости (`pip install -r requirements.txt`)
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))

---

## **Настройка**
### **Создайте `.env` файл**
В корне проекта создайте файл `.env` и добавьте токен бота:
```ini
TELEGRAM_BOT_TOKEN="ваш_токен_бота"
```

### **Запуск сервера**
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
- Сервер будет доступен:  
  - Локально: `http://127.0.0.1:8000`  
  - В сети: `http://ваш-ip:8000`  

---

## **Использование**
### **Telegram-бот**
1. Найдите бота в Telegram и начните диалог.
2. Отправьте команду `/start`, чтобы подписаться на уведомления.
3. При регистрации устройства через API (`POST /register/`) бот пришлет уведомление.
